# Exporting Blazor TreeGrid To PDF with customization

A quick-start Blazor project that depicts how to perform PDF exporting in the Syncfusion [Blazor TreeGrid](https://www.syncfusion.com/blazor-components/blazor-tree-grid). This project also includes code to customize the file name, theme, header, and footer of the exported PDF document.

**Online examples**: https://blazor.syncfusion.com/demos/tree-grid/exporting?theme=fluent2

## Features

* Export TreeGrid data to a PDF document using the built-in PDF export functionality.
* Customize the exported PDF file name.
* Apply custom styling and themes to the exported PDF content.
* Add custom header or footer content to the PDF document.
* Configure page settings such as orientation and page size during export.
* Preserve the hierarchical structure of TreeGrid records in the exported PDF.
* Customize exported document appearance through PDF export properties.
* Trigger PDF export using the built-in TreeGrid toolbar.

## Prerequisites

- Visual Studio 2026 or Visual Studio Code
- [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)


## How to Run the Project

**Visual Studio 2026**

1. Clone or download this repository.
2. Open the project file:

   `ExportTreeGridToPDF.csproj`

3. Restore all NuGet packages.
4. Build the project.
5. Run the application using **Ctrl+F5**.

**Visual Studio Code**

1. Open the repository folder in Visual Studio Code.
2. Open the integrated terminal.
3. Navigate to the repository root.

```bash
cd exporting-blazor-treegrid-to-pdf-with-customization
dotnet restore
dotnet run
```

Open the URL displayed in the terminal after the application starts.
